About Me

Roux Beryl

RPL | SMK Plus Pelita Nusantara

Halo, perkenalkan nama saya Beryl. Saat ini saya duduk di kelas 11 jurusan Rekayasa Perangkat Lunak (RPL) di SMK Plus Pelita Nusantara. Saya tertarik dengan dunia pemrograman dan pengembangan website, sehingga saya terus belajar dan melatih kemampuan saya di bidang ini melalui pelajaran sekolah maupun belajar secara mandiri.

Selama menjadi siswa RPL, saya sudah mempelajari dasar-dasar pembuatan website menggunakan HTML, CSS, dan JavaScript, serta mulai mengenal React untuk membangun tampilan yang lebih interaktif. Saya juga belajar konsep dasar database menggunakan MySQL untuk menyimpan dan mengelola data.

Melalui portfolio ini, saya ingin menunjukkan progres belajar saya sejauh ini sebagai siswa RPL, sekaligus terus mengasah kemampuan agar semakin baik ke depannya.
